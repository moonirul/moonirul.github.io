# 💼 Portfolio Website

This portfolio is built using a clean, responsive **Jekyll** template powered by **Tailwind CSS**, **Bootstrap Icons**, and **Academicons**.

### Local Development

```bash
make install
make serve
```

Open:

```
http://localhost:4000
```

### Production Build

```bash
make build
```

The generated website will be available inside:

```
_site/
```

# 📂 Portfolio Configuration

All editable information is stored inside the `_data` directory.

* `author.yaml` — Personal profile, biography, social links, and contact information
* `experience.yaml` — Education and professional experience
* `publications.yaml` — Research publications and academic work

Sections are automatically hidden when no data is provided.
